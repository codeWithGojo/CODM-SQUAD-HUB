# Squad Hub Mobile Frontend

Expo / React Native implementation of the purple competitive-esports design direction.

## Mobile integration
- Mobile-first dashboard derived from the tournament-dashboard reference
- Compact top app bar + five-tab bottom navigation
- Purple/magenta hero with stylized in-app operator artwork
- Featured tournament carousel with timers, entry rules and slot counts
- Animated count-up stats
- Player Passport redesigned around rating gauges, match trends and CODM metrics
- Connection Check available from Home quick actions and More
- Nigerian ISP starter coverage data with gaming-focused network scoring
- Existing tournament control, scrims, scouting, performance, media, fantasy and admin screens preserved

## Design rules
- Near-black / graphite base
- Purple and magenta are accents, not the entire canvas
- System-native typography for serious product UI
- Bold hero/tournament typography only where broadcast energy helps
- Dense operational screens stay closer to Discord-style information hierarchy

## Run
```bash
npm install
npx expo start
```

Use Expo Go on a physical phone or press `a` / `i` for an emulator.
