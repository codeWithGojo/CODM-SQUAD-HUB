# Squad Hub Architecture

Status: Frozen

Version: 1.0

This document defines the official backend architecture of Squad Hub.

The backend follows a Modular Monolith architecture built with FastAPI.

Core Modules

- Authentication
- Identity
- Organizations
- Teams
- Players
- Tournaments
- Rankings
- Finance
- AI
- Governance
- Reports
- Notifications

Database

- PostgreSQL

Cache

- Redis

Storage

- Cloudflare R2

Payments

- Paystack

Authentication

- Phone OTP
- JWT
